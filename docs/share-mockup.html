Share, dark

A dark take on your orientation mockups, stretched over the whole system. One Go binary serves the website and the API and keeps every file in a folder set in config.json: on the router for now, maybe on a Hetzner VPS later. The website is only for sending: anyone with a PIN, no account. Nothing is family-specific; friends and anyone else with a PIN or an invite see the same screens. The app is for seeing and downloading, and for admins, for running the whole thing. Numbers follow the order in which you'd meet the screens.

Website · installable PWA

Anyone with a PIN can send

Uppy runs headless underneath: tus for resumable uploads, Golden Retriever to survive a closed tab. The screens on top are our own, because Uppy's stock Dashboard shows far more than someone sending a few photos needs. Tablets and computers get their own layouts, below. The language comes from the browser; the globe button on the first screens switches it. Cloudflare sits in front and provides the HTTPS a PWA needs.

Website · tablets and computers

The same pages, using the space

Phones keep the screens above exactly. From 640 points wide (and 540 tall) the pages get a header across the window and one card in the middle; from 1024 wide, Ready, Sending and the invite page get two panes. The size decides the layout, the pointer the wording: with a mouse the page says "drop here" and "this tab", with a touch screen it keeps the phone's words.
